### Необходимые условия

Что нужно установить для работы с Git и GitHub:

| Программа | Зачем нужна |
|-----------|-------------|
| Git | система контроля версий, хранит историю изменений |
| VS Code | редактор для работы с файлами и разметкой |
| GitHub | удалённое хранилище репозиториев |

### Установка

Пошагово, как начать работу с Git:

1. Скачать и установить Git с [официального сайта](https://git-scm.com/downloads)

2. Указать имя и почту пользователя:

```
git config --global user.name "6Daria-D6"
git config --global user.email "Davydovadara590@gmail.com"
```

3. Создать репозиторий на сайте [github.com](https://github.com) и загрузить в него файлы.

## Полезные команды Git

```
git init — создать репозиторий 
git add . — добавить файлы в отслеживание 
git commit -m "комментарий" — сохранить изменения 
git push — отправить изменения на сервер
```
